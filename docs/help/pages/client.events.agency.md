## What this page tells you

The upcoming events {{client}} and its tracked rivals list, for the next 60 days. Client users see the same page.

- Events are grouped by date, and on a shared date {{client}}'s own events come first.
- Each row shows the business, the event name (a link to the event's page when one is known), the start time, where we found it and its status.
- **Source** tells you where the event was listed: **Google** (the business's Google listing), **Website** (the business's own site) or **Meta ad** (an ad that announces it). An event found in more than one place shows each source.
- **Status** is **Scheduled** unless a website says the event is **Cancelled**, **Postponed** or **Sold out**.
- **Time not listed** means the source gave a date but no start time.

The Events entry shows in the menu for clients whose business type lists events, and for any client where {{client}} or a tracked rival has listed an event recently. The page itself opens for every client you can see.

## How to use it

1. **Scan the next few weeks.** Look for dates where several rivals are running events, or where a rival has something {{client}} does not.
2. **Open the event.** Select an event name to see the page where it is listed.
3. **Bring it to the client.** A rival's events, cancellations and sold-out dates make good talking points in a check-in or a brief.

## Common questions

### How often is this updated?

Weekly. New and changed events appear after the next weekly check. Events also feed the weekly changes and briefs.

### Why do I see only a few events for a business?

Google shows up to three upcoming events for a business, so a business that runs more events can have some missing here. Events on a business's own website are added when we read that site, which needs an events page among the rival's tracked pages.

### Why is an event not marked as cancelled or sold out?

An event shows as **Cancelled**, **Postponed** or **Sold out** only when the business's own website says so. Google does not list a status, so an event we only see on Google always reads **Scheduled**.

### Why does a repeating event show up many times?

An event that repeats, such as a weekly class, appears once for each date in the next 60 days.

### Why is the page empty?

Neither {{client}} nor its tracked rivals list any upcoming events that we can find, or the first weekly check has not run yet.
