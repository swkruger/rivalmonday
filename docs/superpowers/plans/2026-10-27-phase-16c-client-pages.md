## Global Constraints
- **No behaviour change (D1):** no route, query param, data, copy, a11y-name or E2E-path change. Content stays; containers, type, spacing and colour move. New copy only where listed in Decisions (owner sign-off line in the work file).
- **New UI only per D11:** the Changes peek panel (Task 6) and the bulk bar on the one existing bulk action, "Track selected (n)" in Suggested competitors (Task 3). No Select all / clear-selection, no applied-filter chips, no mobile list rows, no danger zone (Decisions P4–P6).
- **Tokens, not values** (09 § 0 rule 1); playbook `text-[13px]` → `text-13`, `text-[11px]` → `text-11`. Allowed literals: layout widths/heights, `tracking-[-0.01em]`, chart ramps in `change-grid`/`geo-grid`/`topic-heatmap`/`rank-trend`.
- **White-label:** nothing new reads the agency colour except through `--primary`/`--secondary` (+ derived) and `--you`. Focus is the fixed `--focus` outline (no `ring-primary`).
- **Status grammar (D-10):** pills (`rounded-full`) only for filter chips and the Friday pill; status/category labels are rect (`rounded-xs`) badges, `Tag`, `DotStatus` or `TierMark`. Orange (`accent`/`amber`) only for Friday, priority and stars.
- **Help tips** sit beside headings via `Section` `titleAside` (outside the heading, so its accessible name stays the title) — 16b P-rule. Inline "label ⓘ" tip rows stay as they are.
- Every `PageHeader` keeps `title`, `breadcrumb`, `helpKey`, `guide`; breadcrumbs keep `›`. No route `loading.tsx` (use `Suspense`). The shell sidebar stays the only `<aside>`/complementary landmark: page side columns are `div`s.
- **15c C9 stays:** `ListDetail` below `lg` = list only, detail in a `Sheet` when the URL names an item; every close path pushes `closeHref`.
- **Tests (D16):** class-string assertions move to role / `aria-*` / `data-slot` / `data-variant` / `data-tone` in the task whose change breaks them; E2E stays role-based. A guard against a real bug may assert one class (named per task). If an E2E `toBeInViewport` fails because only vertical position moved, scroll into view in the test; if the element is clipped/hidden, fix the layout (16b rule).
- **Lint (D17):** `pnpm design:lint` report-only; record counts.

## Decisions
Spec D10–D19 and 16b P1–P9 stand. Plan-local (Claude's calls):
- **P1 Segmented look, roles kept.** Every control that switches a view/range of the *same* data takes the Segmented look: Changes route switch (Alerts + brief / All / Archived), Changes evidence views (Side by side / Text changes / Capture details / Whole page), Moves status (Open / Closed / All), Rankings Trend | Compare, Pricing history period, competitor Timeline period. They are URL-driven links (or, for Rankings, a WAI-ARIA tablist that swaps a panel), so they keep their element roles, names and `aria-current`/`aria-selected` — the radiogroup `Segmented` component would change roles and break E2E (`getByRole('link', { name: 'Text changes' })`). `@cs/ui` exports the Segmented classes with `aria-current`/`aria-selected` active states (Task 1); the `Segmented` component itself (client state) has no user in 16c.
- **P2 Filters stay GET forms.** Ads, Reviews, Rankings and Changes filters keep their `<form method="get">`, field `name`s, visible labels, hidden inputs and submit button names ("Apply", "Search", "Show"). They become a toolbar on the sheet (no wrapper; 09 § 6.2), native controls take the shared `nativeSelectClass` (Task 1, backlog "export a shared control class"), submit buttons `variant="outline" size="sm"` (≤ 1 primary per view). **FilterChip: no existing chip-type filter exists in client pages, so FilterChip is not used in 16c**; applied-filter chips with ✕ would add a remove action → BACKLOG.
- **P3 Peek panel = the existing lg detail column with peek chrome** (Changes only). Push layout from `lg` (not 1280): the page auto-selects the first row on `lg`, so an overlay from 1024–1279 would open on every visit. Width `minmax(440px,58%)` (the viewer holds side-by-side snapshots; a fixed 440 px would halve them). Header: label "Change details" (existing `detailTitle`), Previous / Next (links within the current page of results, filters kept, `scroll={false}`), Close (only when `?event=` is in the URL; closes to today's `closeHref`). Esc inside the panel = Close and returns focus to the open row. No "Open full page ↗" (events have no page of their own). Below `lg` the C9 sheet is unchanged. **New copy (owner signs):** aria-labels "Previous change", "Next change", "Close details".
- **P4 Bulk bar** wraps the existing "Track selected (n)" bar only: `BulkBar` (`role="toolbar"`, **new label "Selected suggestions"**, owner signs), same button name/disabled rules and limit messages (now `role="status"` so they are announced). No count text, Select all or ✕ (new behaviour → BACKLOG).
- **P5 No danger zone in 16c.** Client settings have no destructive settings action today (pause/archive live in the agency client menu → 16e; recipient "Deactivate" is a row action with its ConfirmDialog, unchanged). Frame 9's danger zone → 16e if that page has one, else BACKLOG.
- **P6 Tables stay tables at 390.** Flush tables scroll inside their own container (Table already wraps `overflow-x-auto`); Frame 10's stacked mobile rows are new responsive UI → 16f (D12). The existing E2E "no module page scrolls sideways" guards it.
- **P7 Competitor detail (Frame 9, D-21):** PageHeader `variant="detail"` with a 40 px `BusinessAvatar` (initials, `aria-hidden`; the h1 names it). Body grid `xl:grid-cols-[minmax(0,1fr)_320px]` (main | side column with `xl:border-l`), stacked below `xl` (at 1024 the sheet is ~710 px — a 320 px column would leave the KPIs ~390 px). Main: rated row, KPI strip, the four module sections in a 2-col hairline grid, Timeline, Pages (Frame). Side column: Collection status as definition rows. **One DOM-order change:** Pages now precedes Collection status (the 6-column Pages table can't live in 320 px). KPI tiles without a number show "—" as the value with today's sentence ("No rating yet", "No Google profile yet") as the caption (catalogue: empty value "—").
- **P8 Save model per form (08 § 8):** forms that already use `SaveBar` keep it (profile, features, delivery, alert rules). `ClientDetailsForm` (8 fields + logo, explicit "Save details" button) moves to `SaveBar saveLabel="Save details"` (Form archetype, Frame 6); Discard restores the initial values and clears the file input. Each `SaveBar` is sticky inside its own `<form>`, so bars of sibling forms never overlap. Single-action forms (Add competitor, Add recipient, Add page) keep their button.
- **P9 Suggestions are interactive cards** (09 § 6.2, Frame 5): each suggestion `li` holds a `Card variant="interactive" selected={checked}` in a `sm:grid-cols-2` grid per tier; the checkbox stays the control and the selected state is not colour-only (checkbox). Tier group headings render `TierMark` (same text, so the h3 name "Top rival · 3" is unchanged).
- **P10 Runbook editor → 16e.** `components/runbook/*` serves the agency and platform runbook pages too; the client runbook page has no containers of its own, so 16c leaves it (shot route added, ungated). `ai-connections.tsx` is migrated here (client AI page is in scope); the agency AI settings page inherits it.
- **P11 StatCard retired here:** the five remaining groups (client Reviews; agency dashboard; platform overview, billing, agency detail) swap to `StatStrip` with the same items; `StatPill` moves to `stat-strip.tsx`; `stat-card.tsx` and its test are deleted. Nothing else on the agency/platform pages changes (16e).
