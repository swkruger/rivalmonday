# Phase 6a — Tool catalogue hardening + remote MCP server: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose the `@cs/tools` catalogue to Claude, ChatGPT and scripts through a remote MCP server at `/mcp` (Streamable HTTP, stateless), authenticated by OAuth 2.1 (DCR + PKCE + refresh, consent with workspace pick) or personal access tokens, with hybrid `search`/`fetch`, per-token rate limits, audit-log metering and an "AI connections" UI.

**Architecture:** `@cs/core` registry gains channels, token scopes and hidden-tool parity. New `@cs/mcp` owns token resolution, rate windows, the MCP server (registry tools, resources, prompts) and `handleMcpRequest(Request)`. `apps/web` mounts it at `/mcp`, serves `.well-known` metadata, hosts the Better Auth OAuth provider, `/oauth/consent` and the AI connections pages. `search`/`fetch` are `@cs/tools` tools (FTS + pgvector, RRF).

**Tech stack:** existing (Node 24, pnpm 10, Turborepo, Next 16.3.8, Better Auth 1.7.7, Drizzle 0.44, Zod 4, Vitest 3, Playwright 1.63) + **`@better-auth/oauth-provider@1.7.7`** (apps/web) + **`@modelcontextprotocol/sdk@1.30.1`** (published 2026-09-23; newest release ≥ 2 weeks old on 2026-10-11; peer `zod ^3.25 || ^4.0`; ships `WebStandardStreamableHTTPServerTransport` and a client `StreamableHTTPClientTransport` with a `fetch` option).

**Spec (binding):** [`docs/superpowers/specs/2026-10-11-phase-6a-mcp-design.md`](../specs/2026-10-11-phase-6a-mcp-design.md) (decisions d1–d13). Core spec §8.2, §8.3, §11 only where cited.

## Global constraints
- **Rate limits (d9):** `RATE_LIMITS = { perMinute: 60, perDay: 2000 }`, fixed windows in Postgres (`mcp_rate_window`), per token key `pat:<api_token.id>` | `oauth:<consent_id>`.
- **PAT format:** `rm_pat_` + 32 random bytes in base62 (43 chars, left-padded with `0`). Shown once; stored as `sha256(token)` hex; `token_prefix` = first 12 chars.
- **Scopes:** `read` ⊂ `feedback` ⊂ `manage`. Grantable only if the role holds the permission; `manage` only for agency roles in 6a; `client_viewer` only `read`. Effective permission = role ∩ token scope ∩ per-client `mcp` feature (agency roles bypass features).
- **d12:** every captured text returned over a non-`web` channel passes through `redactForModel` (`@cs/collectors`), never bare `redactContactInfo`.
- **404 not 403:** unknown and hidden tools both throw `ToolError('not_found', \`Unknown tool: ${name}\`)` (identical text); items out of scope → `not_found`; page refusals → `notFound()`.
- **Invariants:** event readers filter `retracted_at IS NULL`; `search`/`fetch` and bound tokens require `client.status = 'active'`; `upsell_tag` never reaches client roles; web reads are registered tools, web writes go through `runTool`.
- **No caching of token validity (d13):** every `/mcp` request re-resolves token, membership, client status.
- **Repo:** LF only (`git ls-files --eol | grep crlf` prints nothing). Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (subagents may name their own model). Never stage `.env`, `.claude/` (except `.claude/skills/rm-*`), `App/`, `.superpowers/`. Never edit applied migrations.
- **Tests:** local test cluster only (`bash scripts/local-test-db.sh start`), this worktree's own DB `cs_phase_6_test` (Task 0). Never two test runs (E2E included) on one DB. Implementers run focused tests in the foreground: `pnpm --filter <pkg> exec vitest run <pattern>` (`test -- <pattern>` does not narrow). Reviewers run `pnpm test:affected` and, for web-facing tasks, `pnpm --filter @cs/web e2e:affected`. Full suite/E2E only in `/rm-merge`.
- **Next.js:** read `apps/web/node_modules/next/dist/docs/` for APIs touched; `params`/`headers()`/`cookies()` are async. **Env:** no new vars planned; any new one needs the owner's OK and `turbo.json` `globalPassThroughEnv`.

## Decisions
Spec d1–d13 are binding and not restated. **Plan-local** (owner confirms with plan approval):
- **P1** Keep `invoke(ctx, name, input, opts?)`, `list(ctx, opts?)`, `describe(ctx, opts?)` (spec says `call`); `opts` defaults to `{ channel: 'web' }`, so current callers are unchanged.
- **P2** Handlers get an optional 4th arg `meta: { channel, tokenId }` (summary default, limit cap, d12 redaction per channel).
- **P3** Unknown and hidden tools throw identical errors, but the audit row keeps `permission_denied` for hidden (internal only).
- **P4** Channel `mcp`: a client role without the client's `mcp` feature sees no tools, but the request is not 401 (avoids OAuth re-auth loops). An `mcp` call without `tokenScope` sees nothing.
- **P5** New inputs are camelCase like the other ~80 tools (`search` takes `clientId`); `search`/`fetch` outputs keep the spec's ChatGPT shapes (`metadata.client_id`, `evidence_ids`); summary rows use `evidenceIds`.
- **P6** `withTenant` also sets `app.user_id`/`app.role` (SQL `app_user_id()`, `app_role()`) for the spec's RLS. `app_user`: column-limited `SELECT` on `api_token` (never `token_hash`), `UPDATE (revoked_at)` on both token tables; inserts are service-role after TS checks (house pattern).
- **P7** `oauth_grant_binding` gains `id uuid UNIQUE` (audit `token_id` is uuid, consent ids are text) and `oauth_client_id`; both token tables FK `user_id` → `auth."user"` (as `membership`).
- **P8** Effective OAuth scope = `binding.scope` capped by the live role; the consent page is the authority, not the token's scope list.
- **P9** Consent picker = the user's memberships (active client + `mcp` feature for client roles); one option → read-only; a single agency membership reads "all clients you can access". The binding is written by the auth flow (service role, like `acceptInvitations`), not via `runTool`.
- **P10** Token tools: permission `read`, feature `mcp`, refuse guests, ≤ 20 active PATs per user. Agency roles create agency-wide tokens on `/agency/ai`; client roles client-bound ones on `/c/<id>/settings/ai`.
- **P11** `url` = `/go/<t>/<id>` for `/go`'s targets (brief, brief_item, alert); direct page paths for the rest (event, evidence, recommendation, review, page, move, competitor, client — `/go` can't pick a client for them). `ToolDeps.appUrl` makes them absolute.
- **P12** Cursor = base64url `{"o":offset}`; `detail` defaults to `summary` off-web and `full` on web; off-web `limit` ≤ 50.
- **P13** FTS `search_tsv` columns are SQL-only (not in Drizzle). No ANN vector index yet (→ BACKLOG).
- **P14** New tool `add_recommendation` (d5's add-from-finding; none exists): `channels ['mcp']`, `recommendation.source` gains `'mcp'`.
- **P15** White-label name = `agency.branding.displayName` (trimmed) else `'Rival Monday'` (no `productName` field exists).
- **P16** `ToolDeps.embedQuery` only in the `dev` environment with `OPENROUTER_API_KEY`; else FTS-only (tests/DEMO/TEST/E2E never call OpenRouter).
- **P17** Rate limits count `tools/call` and `resources/read` only.
- **P18** `fetch` of global types (event, evidence, review, page) with an agency token uses the first active client in scope (by name, id) that can see it.

## Review focus
1. **Cross-tenant leakage via `search`/`fetch`** (global event/review/capture_block/evidence rows are shared) → T5 `never returns another client's event on a shared competitor`, T6 `fetch of an event scored only for another client is not_found`, T14 cross-agency probe.
2. **Token reach after live changes** (membership removed, AM scope shrunk, client not active, owner→viewer) → T7 `tokenAccess returns null after membership removal`, `caps scope after role downgrade`, `narrows an account manager to the live scope`; T14 `revocation applies on the next call`.
3. **PAT shown twice, stored or logged in plaintext** → T12 `returns the token once and stores only its hash`, `list never includes token or hash`, `no token text reaches console output`; T3 `app_user cannot select token_hash`.
4. **Consent binding race / re-consent** (code before binding; re-consent upgrading old tokens; tampered form; revoked grant silently re-used) → T11 `binding exists before the redirect`, `re-consent with a different workspace revokes earlier tokens`, `rejects a membership the user does not hold`; T12 `revoke_oauth_grant deletes the plugin consent`.
5. **Rate-window concurrency/rollover** → T8 `61 concurrent calls admit exactly 60`, `minute rollover resets`, `day cap returns seconds to UTC midnight`, `keys are isolated`.

```ts
const RANK: Record<TokenScope, number> = { read: 0, feedback: 1, manage: 2 };
export const scopeCovers = (have: TokenScope, need: TokenScope) => RANK[have] >= RANK[need];
export function grantableScopes(role: Role): TokenScope[] {
  if (isAgencyRole(role)) return ['read', 'feedback', 'manage'];
  return role === 'client_owner' ? ['read', 'feedback'] : ['read']; // d4/d5: no manage for client roles in 6a
}
export function effectiveScope(granted: TokenScope, role: Role): TokenScope {
  const max = grantableScopes(role).at(-1)!;
  return RANK[granted] <= RANK[max] ? granted : max;
}
const ALPHABET = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz';
const BODY = 43; // ceil(256 / log2 62)
export function generatePat(random: (n: number) => Uint8Array = (n) => randomBytes(n)) {
  let n = BigInt(`0x${Buffer.from(random(32)).toString('hex')}`);
  let body = '';
  while (n > 0n) { body = ALPHABET[Number(n % 62n)] + body; n /= 62n; }
  const token = PAT_PREFIX + body.padStart(BODY, '0');
  return { token, hash: hashPat(token), prefix: token.slice(0, 12) };
}
export const hashPat = (token: string) => createHash('sha256').update(token, 'utf8').digest('hex');
export const isPatFormat = (s: string) => /^rm_pat_[0-9A-Za-z]{43}$/.test(s);

// tools.ts — visibility (replaces isAllowed)
const CHANNEL_FEATURE: Partial<Record<ToolChannel, Feature>> = { mcp: 'mcp', ask: 'ask' };
function isVisible<D>(ctx: AccessContext, tool: AnyTool<D>, opts: CallOptions): boolean {
  if (!(tool.channels ?? ['web']).includes(opts.channel)) return false;
  if (!hasPermission(ctx, tool.permission)) return false;
  const agency = isAgencyRole(ctx.role);
  if (tool.feature && !agency && !ctx.features.has(tool.feature)) return false;
  const chf = CHANNEL_FEATURE[opts.channel];
  if (chf && !agency && !ctx.features.has(chf)) return false;
  if (opts.channel === 'mcp' && !opts.tokenScope) return false;          // P4: fail closed
  if (opts.tokenScope && !scopeCovers(opts.tokenScope, mcpScopeOf(tool))) return false;
  return true;
}
```

```ts
export function rrfMerge<T extends { key: string }>(lists: readonly (readonly T[])[], k = 60, limit = 10): T[] {
  const acc = new Map<string, { item: T; score: number; best: number }>();
  for (const list of lists) {
    list.forEach((item, i) => {
      const add = 1 / (k + i + 1);
      const prev = acc.get(item.key);
      if (prev) { prev.score += add; prev.best = Math.min(prev.best, i); }
      else acc.set(item.key, { item, score: add, best: i }); // first list wins the displayed item (FTS has the better snippet)
    });
  }
  return [...acc.values()]
    .sort((a, b) => b.score - a.score || a.best - b.best || a.item.key.localeCompare(b.item.key))
    .slice(0, limit).map((x) => x.item);
}
```

```ts
export interface ResolvedToken { kind: 'pat' | 'oauth'; tokenKey: string; tokenId: string; userId: string; agencyId: string; clientId: string | null; scope: TokenScope }
/** Wired by apps/web in Task 11: verifies an opaque OAuth access token and returns its user and consent, or null. */
export type VerifyOAuth = (token: string) => Promise<{ userId: string; consentId: string } | null>;

const BEARER = /^Bearer[ ]+([\x21-\x7e]{1,4096})$/i;

export async function resolveBearer(d: { service: Db; verifyOAuth: VerifyOAuth | null }, authorization: string | null): Promise<ResolvedToken | null> {
  const raw = authorization?.match(BEARER)?.[1];
  if (!raw) return null;
  if (raw.startsWith(PAT_PREFIX)) {
    if (!isPatFormat(raw)) return null;
    const [t] = await d.service.select({ id: apiToken.id, userId: apiToken.userId, agencyId: apiToken.agencyId, clientId: apiToken.clientId, scope: apiToken.scope })
      .from(apiToken).where(and(eq(apiToken.tokenHash, hashPat(raw)), isNull(apiToken.revokedAt)));
    if (!t) return null;
    return { kind: 'pat', tokenKey: `pat:${t.id}`, tokenId: t.id, userId: t.userId, agencyId: t.agencyId, clientId: t.clientId, scope: t.scope as TokenScope };
  }
  if (!d.verifyOAuth) return null;
  const info = await d.verifyOAuth(raw).catch(() => null);
  if (!info) return null;
  const [b] = await d.service.select().from(oauthGrantBinding)
    .where(and(eq(oauthGrantBinding.consentId, info.consentId), eq(oauthGrantBinding.userId, info.userId), isNull(oauthGrantBinding.revokedAt)));
  if (!b) return null;
  return { kind: 'oauth', tokenKey: `oauth:${b.consentId}`, tokenId: b.id, userId: b.userId, agencyId: b.agencyId, clientId: b.clientId, scope: b.scope as TokenScope };
}

export async function tokenAccess(service: Db, t: ResolvedToken): Promise<{ ctx: AccessContext; scope: TokenScope } | null> {
  const ms = await listMemberships(service, t.userId);
  const m = ms.find((x) => x.agencyId === t.agencyId && (t.clientId === null ? isAgencyRole(x.role) : !isAgencyRole(x.role) && x.clientId === t.clientId));
  if (!m) return null;
  if (t.clientId !== null) {
    const [c] = await service.select({ status: client.status }).from(client).where(and(eq(client.id, t.clientId), eq(client.agencyId, t.agencyId)));
    if (c?.status !== 'active') return null;
  }
  return { ctx: await accessContextFor(service, t.userId, m), scope: effectiveScope(t.scope, m.role) };
}

}
```

```ts
export const RATE_LIMITS = { perMinute: 60, perDay: 2000 } as const;
const MIN = 60_000, DAY = 86_400_000;

export async function checkRateLimit(db: Db, tokenKey: string, now: Date = new Date()): Promise<{ ok: true } | { ok: false; retryAfterS: number }> {
  const t = now.getTime();
  const minuteStart = new Date(Math.floor(t / MIN) * MIN);
  const dayStart = new Date(Math.floor(t / DAY) * DAY); // UTC midnight
  // One statement: both windows are bumped atomically; concurrent calls serialise on the row locks of ON CONFLICT.
  const rows = [...(await db.execute<{ kind: 'minute' | 'day'; count: number }>(sql`
    INSERT INTO mcp_rate_window (token_key, window_kind, window_start, count)
    VALUES (${tokenKey}, 'minute', ${minuteStart.toISOString()}::timestamptz, 1),
           (${tokenKey}, 'day', ${dayStart.toISOString()}::timestamptz, 1)
    ON CONFLICT (token_key, window_kind, window_start) DO UPDATE SET count = mcp_rate_window.count + 1
    RETURNING window_kind AS kind, count`))];
  const minute = rows.find((r) => r.kind === 'minute')!.count;
  const day = rows.find((r) => r.kind === 'day')!.count;
  if (day === 1) {
    await db.execute(sql`DELETE FROM mcp_rate_window WHERE token_key = ${tokenKey} AND window_start < ${new Date(dayStart.getTime() - DAY).toISOString()}::timestamptz`);
  }
  if (day > RATE_LIMITS.perDay) return { ok: false, retryAfterS: Math.max(1, Math.ceil((dayStart.getTime() + DAY - t) / 1000)) };
  if (minute > RATE_LIMITS.perMinute) return { ok: false, retryAfterS: Math.max(1, Math.ceil((minuteStart.getTime() + MIN - t) / 1000)) };
  return { ok: true };
}
```

```ts
export interface ConsentOption { membershipId: string; label: string; agencyId: string; clientId: string | null; scopes: TokenScope[] }
export type ConsentTarget = { agencyId: string; clientId: string | null; scope: TokenScope };

/** P9 + d4: what this user may bind. Client options need an active client with the `mcp` feature. */
export async function consentOptions(service: Db, userId: string, requested: string | null): Promise<ConsentOption[]> {
  const asked = (requested ?? '').split(/\s+/).filter((s): s is TokenScope => (TOKEN_SCOPES as readonly string[]).includes(s));
  const cap: TokenScope | null = asked.length ? asked.reduce((a, b) => (scopeCovers(a, b) ? a : b)) : null;
  const out: ConsentOption[] = [];
  for (const m of await listMemberships(service, userId)) {
    const agency = isAgencyRole(m.role);
    if (!agency) {
      const [c] = await service.select({ status: client.status, features: client.features }).from(client).where(eq(client.id, m.clientId!));
      if (c?.status !== 'active' || !(c.features ?? []).includes('mcp')) continue;
    }
    const scopes = grantableScopes(m.role).filter((s) => cap === null || scopeCovers(cap, s));
    if (!scopes.length) continue;
    out.push({ membershipId: m.id, agencyId: m.agencyId, clientId: agency ? null : m.clientId, scopes,
      label: agency ? `${m.agencyName}: all clients you can access` : `${m.clientName} (${m.agencyName})` });
  }
  return out;
}

export function pickConsent(options: ConsentOption[], membershipId: string, scope: string): ConsentTarget | null {
  const o = options.find((x) => x.membershipId === membershipId);
  if (!o || !(o.scopes as string[]).includes(scope)) return null; // tampered form
  return { agencyId: o.agencyId, clientId: o.clientId, scope: scope as TokenScope };
}

/**
 * Review focus 4: written after the plugin accepted the consent and BEFORE the browser gets the redirect carrying the
 * code. A re-consent that changes workspace, scope or user revokes every token issued under the old binding.
 */
export async function bindConsent(service: Db, b: { consentId: string; oauthClientId: string; userId: string; target: ConsentTarget }): Promise<void> {
  await service.transaction(async (tx) => {
    const [prev] = await tx.select().from(oauthGrantBinding).where(eq(oauthGrantBinding.consentId, b.consentId)).for('update');
    const changed = prev && (prev.revokedAt !== null || prev.userId !== b.userId || prev.agencyId !== b.target.agencyId || prev.clientId !== b.target.clientId || prev.scope !== b.target.scope);
    if (changed) await revokePluginTokens(tx, b.userId, b.oauthClientId);
    await tx.insert(oauthGrantBinding)
      .values({ consentId: b.consentId, oauthClientId: b.oauthClientId, userId: b.userId, agencyId: b.target.agencyId, clientId: b.target.clientId, scope: b.target.scope })
      .onConflictDoUpdate({ target: oauthGrantBinding.consentId, set: { oauthClientId: b.oauthClientId, userId: b.userId, agencyId: b.target.agencyId, clientId: b.target.clientId, scope: b.target.scope, revokedAt: null, createdAt: new Date() } });
  });
}
```
