## 2. Interfaces

- **`PageKey`** (`apps/web/src/help/copy/index.ts`): extends to all 61 keys from the inventory; copy split per context file `help/copy/{client,agency,platform,account}.ts`, merged into `PAGE_COPY`. Key ids follow 15b-1 Q1 (route menu identity, dot-separated; detail pages `.detail`).
- **Guides:** `docs/help/pages/<context>.<page>[.<audience>].md` (15b-1 format, three fixed H2 sections). Platform pages default to `.operator` unless the text is safe for `all`.
- **`list_help_guides`** (`packages/tools/src/tools/help.ts`): context filter becomes `help_key LIKE 'page:<context>.%' OR help_key LIKE 'page:account.%'`. `get_page_guide` unchanged.
- **`groupGuides`** (`apps/web/src/components/help/help-groups.ts`): adds the "Your account" group (C6).
- **Coverage test** `apps/web/src/help/coverage.test.ts` (new): statically scans `apps/web/src/app/**/page.tsx` for `<PageHeader`; asserts each passes `helpKey=` (except the C5 exempt list, declared in the test); every `helpKey` used has a guide file for each audience that can reach the page (client pages: agency + client, or `all`; agency pages: agency or `all`; platform: operator or `all`; account: every audience of that page); every `tip=` / `TipKey` literal resolves in `PAGE_COPY`. Fails listing all gaps.
- **Glossary** (`packages/core/src/help/glossary.ts`): term `theme` → id `topic`, term "Topic" (C3); new terms as the audit §3 needs; still no placeholders.
- **C4 components:** `PressureBadge` and the approval confidence indicator render a visible text label ("High/Medium/Low pressure", "High/Medium/Low confidence"); heatmap legend inside `ThemeHeatmap` (component name unchanged until 15b-3); Setup form groups lat/lng/place id under a closed-by-default "Advanced" disclosure with `FieldHint`s.

## 3. Rules carried from 15b-1
Audience isolation (client roles never get agency/operator text — tips with agency-only content set `audience: 'agency'`); no "Rival Monday", neutral fallbacks; `{assistant}`/`{{assistant}}` never "Friday"; copy derived from code with `// source:` comments for metrics; US English, sentence case, miles in copy (unit conversion of values is 15c); `EmptyState` honours `audience`; each pilot-style page calls `helpGuides` with the scope `PageGuide` derives.

## 4. Testing
Unit: coverage test (§2); `help-content.test.ts` seeds the real `docs/help` and checks every page key + audience; leak test extended to every client-reachable page's copy; `groupGuides` "Your account"; `list_help_guides` account rows per context; C4 components (label text present, no colour-only state, Advanced closed by default). E2E: one smoke per batch (guide opens with the right version) added to `e2e/help.spec.ts`.
