## Pattern observations (owner evidence)
1. **Owner strongly favours Plain** (14 of 29 screens). Plain's language: grey app frame, inset white main panel (radius ~8px, 1px border), dual nav (icon rail + grouped text sub-nav), centred content column for settings/forms, black (near-ink) primary buttons, hairline-divided lists, charts directly on the page, tiny status pills with dot, no shadows. → strongest single signal of taste.
2. **Card usage in owner picks is selective**: flush tables (O13), charts without frames (O10), plain forms (O01, O05–O07, O17, O27); cards only for catalogues of independent items (O03), editable records (O09), save-together panels (O08), bordered functional groups (radio group O07, status row O23, getting-started strip O13). Card-heavy screens (O14, O15, O16 Amplitude/Causal) are the older Dashboard collection (Feb 2026); newer picks (Oct 2026) are card-light → taste moved toward restraint.
3. **KPI strips**: inline stats w/o containers (O12) or one bordered strip split by vertical dividers (O13). Neither uses one card per KPI. Amplitude tile-per-KPI (O16) is the counterexample.
4. **Onboarding**: centred single column, no stepper chrome (O17), or checklist with inline expansion + side timeline (O24/O26), or thin top progress line (O27). Split screens only for sign-up/checkout (O18–O20). Auth-card-on-grey only for logged-out (O28/O29).
5. **Buttons**: primary is dark/near-black (Plain, Braintrust, Browserbase "Upgrade") or brand colour (Jasper/Amplitude/Causal blue, Mercury indigo). Secondary = white with 1px border. Destructive filled red used once (O04). Sizes compact ~30–32px. Mercury uses full pills; Plain/Browserbase 6px.
6. **Status**: small pill with leading dot ("Connected", "Active", "On standby") or soft-tinted rounded rect ("Completed"). Uppercase outlined (Jasper) feels dated.
7. **Settings**: settings get their own sub-nav replacing/augmenting the main nav (Plain, Jasper); content column narrow (~640–720px), left-aligned within a centred column.
8. **Typography**: neutral grotesk sans (Plain uses a geometric/grotesk ~ Inter-like), titles 20–24px medium (not extra-bold), section heads 14px semibold, body 13px, helper 12px muted.
9. **Inputs**: Plain = white with 1px border radius 6px; Mercury = filled grey no border. Focus = 2px coloured ring (Jasper purple).

## Counter-evidence
- Plain's main panel *is* a container (inset rounded white sheet on grey frame) — the "frame + sheet" shell is itself a big card. It replaces per-section cards, though.
- Mercury/Jasper use pill buttons; Plain/Browserbase use 6px. Mixed.
- Braintrust tints list rows and uses pastel entity colours — more colour than hypothesis.
